# ICONOGRAPHY.md

> Version: 2.0
>
> Purpose
>
> Define the complete icon system used across the portfolio.
>
> Icons should improve comprehension.
> They should never become decoration.

---

# Philosophy

Icons support content.

They never replace content.

If removing an icon does not reduce understanding,
the icon probably isn't needed.

Text is primary.

Icons are secondary.

---

# Design Goals

Icons should feel

✓ Minimal

✓ Professional

✓ Consistent

✓ Lightweight

✓ Functional

✓ Technical

Never feel

❌ Decorative

❌ Cartoonish

❌ Colorful

❌ 3D

❌ Emoji-like

❌ AI Generated
