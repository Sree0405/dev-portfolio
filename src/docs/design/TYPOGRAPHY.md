# TYPOGRAPHY.md

> Version: 2.0
>
> Purpose:
>
> Define the complete typography system for the portfolio.
>
> Typography should create hierarchy, improve readability,
> and communicate professionalism.
>
> The portfolio should feel editorial, modern, and engineered.

---

# Philosophy

Typography is the primary visual language.

Layout creates structure.

Typography creates meaning.

Color only guides attention.

Good typography should be invisible.

Users should never think about fonts.

They should effortlessly understand the content.

---

# Design Goals

Typography should feel

✓ Professional

✓ Premium

✓ Calm

✓ Modern

✓ Technical

✓ Trustworthy

Never feel

❌ Playful

❌ Futuristic

❌ Gaming

❌ AI Generated
