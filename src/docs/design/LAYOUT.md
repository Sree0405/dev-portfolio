# LAYOUT.md

> Version: 2.0
> Purpose:
>
> Define the structural foundation of the portfolio.
>
> Every page should feel consistent, balanced, and easy to navigate.
>
> Layout is responsible for hierarchy—not colors.

---

# Philosophy

Good layouts disappear.

Visitors should focus on the content,
not the structure.

Whitespace is an active design element.

Every section should naturally lead into the next.

---

# Core Principles

✓ Consistent spacing

✓ Predictable rhythm

✓ Strong hierarchy

✓ Responsive by default

✓ Readability first

✓ Content-driven

Never position elements just to fill empty space.

# Alignment Rules

Text

# Whitespace Rules

Do not fill empty areas with:

Random icons

Trust whitespace.

---

# Empty Space

Whitespace is intentional.

Every empty area should have a purpose:

Improve readability

Create focus

Separate ideas

Guide the eye

Do not fill space just because it exists.

---

# Visual Hierarchy

Priority

1. Hero Heading

2. Section Heading

3. Project Screenshot

4. CTA

5. Supporting Text

6. Metadata

Everything cannot have equal emphasis.

---

# Rhythm Checklist

✓ Equal section spacing

✓ Consistent card spacing

✓ Consistent text widths

✓ Predictable layouts

✓ Clear reading flow

✓ Balanced whitespace

✓ Responsive grids

---

# Things To Avoid

❌ Different spacing in every section

❌ Random grid layouts

❌ Uneven card heights

❌ Decorative fillers

❌ Oversized images

❌ Center-aligned paragraphs

❌ Inconsistent alignment

❌ Excessive nested containers

---

# Layout Motto

A visitor should never notice the layout.

They should only notice how effortless it feels to navigate.
