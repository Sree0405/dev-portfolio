# SPACING.md

> Version: 2.0
>
> Purpose
>
> Define the spacing system used across the entire portfolio.
>
> Spacing creates hierarchy, rhythm, readability, and consistency.
>
> Every margin, padding, and gap must come from this document.
>
> Never use arbitrary spacing.

---

# Philosophy

Whitespace is not empty space.

Whitespace communicates structure.

Good spacing reduces cognitive load.

Spacing should create rhythm,
not decoration.

The user should never notice spacing.

They should only notice how easy the interface feels to read.

---

# Design Principles

✓ Consistent

✓ Predictable

✓ Intentional

✓ Token Driven

✓ Responsive

✓ Scalable

Never invent spacing values.
